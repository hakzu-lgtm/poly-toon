# 웹툰 메이커 — 사용 설명서

> 한국폴리텍대학 충주캠퍼스 교직원용 웹툰 자동 생성 도구

## 꼭 읽어 주세요: 본인 API 키로 실행합니다

- 이 프로그램은 **각자 자기 PC에서** 실행하고, 설정 화면에 **본인의 FactChat API 키**를 입력해서 씁니다.
- 이미지를 만들 때마다 **키 주인의 크레딧**이 차감됩니다. 키를 다른 사람과 공유하지 마세요.
- 키와 작업물은 내 PC(또는 내 Codespace)에만 저장되며, 이 저장소에는 올라가지 않습니다.

---

## 설치 방법 A — 내 PC에서 실행 (Windows)

### 처음 한 번만
1. **Python 설치**: https://www.python.org/downloads/ 에서 Python 3.12를 내려받아 설치합니다.
   설치 첫 화면 아래의 **"Add python.exe to PATH"를 반드시 체크**하세요.
2. **프로그램 내려받기**: https://github.com/hakzu-lgtm/poly-toon 에서
   초록색 **Code** 버튼 → **Download ZIP**을 누르고, 원하는 폴더에 압축을 풉니다.

### 실행할 때마다
1. 압축을 푼 폴더에서 `start.bat`을 **더블클릭**합니다.
2. 브라우저가 자동으로 열립니다 (`http://localhost:8000`).
   처음 실행할 때는 필요한 프로그램을 설치하느라 1~2분 걸립니다.
3. 검은 창(서버)을 닫으면 프로그램이 종료됩니다. 사용하는 동안에는 닫지 마세요.

> 이 PC에서만 접속할 수 있도록 설정되어 있어, 같은 네트워크의 다른 사람이 내 키를 쓸 수 없습니다.

### 새 버전으로 업데이트
새 ZIP을 내려받아 압축을 푼 뒤, 기존 폴더의 **`config` 폴더**(API 키·설정)와 **`outputs` 폴더**(작업물)를 새 폴더로 복사합니다.

## 설치 방법 B — 설치 없이 웹에서 실행 (GitHub Codespaces)

Python을 설치하기 어렵다면, GitHub 계정만으로 브라우저에서 실행할 수 있습니다.

1. GitHub에 가입·로그인합니다 (무료).
2. https://github.com/hakzu-lgtm/poly-toon 에서 **Code** → **Codespaces** 탭 → **Create codespace on main**을 누릅니다.
3. 처음에는 준비에 3~5분 걸립니다. 완료되면 웹툰 메이커 화면이 새 탭으로 열립니다.
   열리지 않으면 아래쪽 **PORTS** 탭에서 8000번 포트의 지구본 아이콘을 누르세요.
4. 설정 화면에 **본인 API 키**를 입력합니다.

주의
- Codespace는 **본인 GitHub 계정으로만** 접속할 수 있습니다. 포트 공개 설정(Public)은 바꾸지 마세요.
- 무료 사용 시간은 한 달 약 60시간입니다. 30분 동안 사용하지 않으면 자동으로 멈추며,
  https://github.com/codespaces 에서 다시 열 수 있습니다.
- 30일 동안 사용하지 않은 Codespace는 삭제됩니다. **완성한 웹툰은 내보내기로 내려받아** 두세요.

## 크레딧 아끼기

FactChat 크레딧은 월 단위로 지급되며, **이미지 한 장마다** 차감됩니다 (텍스트 비용은 매우 적음).

- 설정 화면의 **패널당 최대 칸 수**: 칸 하나가 이미지 한 장입니다. 1~2칸을 권장합니다.
- **이미지 품질**: 초안은 "낮음", 최종본만 "보통/높음"으로 만드세요.
- 처음에는 **1장(6컷) 정도로 작게** 만들어 보고, 마음에 들면 늘리세요.
- 크레딧이 부족하면 생성이 자동으로 멈추고 안내 메시지가 표시됩니다.
- 연결 테스트는 크레딧을 쓰지 않습니다.

## 사용 순서

### Stage 0 — 설정 / API 연결
- FactChat API 키를 입력하고 **설정 저장**을 클릭합니다.
- **연결 테스트**를 눌러 텍스트·이미지 모델 확인이 모두 "성공"인지 확인합니다 (크레딧 차감 없음).

### Stage 1 — 웹툰 설정
- **핵심 키워드**: 웹툰의 주제를 간단히 적습니다 (예: 신입생 환영, 안전교육).
- **그림체**: 12종 미리보기 중 원하는 스타일을 클릭합니다.
- **장 수**: 긴 스토리는 여러 장으로 나누고, 장마다 컷 수를 지정합니다.
- "설정 저장 후 다음 →"을 클릭합니다.

### Stage 2 — 스토리 생성
- **스토리 생성**을 누르면 AI가 시놉시스, 등장인물, 컷별 시나리오를 자동 작성합니다.
- 결과를 확인하고, 수정이 필요하면 직접 편집하거나 **다시 생성**합니다.
- JSON 직접 편집도 가능합니다.

### Stage 3 — 캐릭터 시트 & 표지
- **캐릭터 시트 + 표지 생성**을 누르면 등장인물별 3종 뷰(정면/3/4/표정)와 표지가 생성됩니다.
- 진행률이 실시간으로 표시됩니다.
- 마음에 들지 않는 캐릭터는 **전체 다시 생성**으로 개별 재생성 가능합니다.

### Stage 4 — 컷 이미지
- 컷마다 이미지가 생성됩니다. 한 컷은 설정한 칸 수(기본 3칸, 최대 4칸)만큼 이미지를 사용합니다.
- 컷 분할(사선, 2×2, 세로 긴 칸 등)은 장면에 맞게 자동으로 정해지고, 인물 얼굴이 잘리지 않게 칸에 맞춰 자릅니다.
- 후보가 여러 장이면 마음에 드는 후보를 **클릭**하여 선택합니다.
- 특정 컷은 수정 지시를 적어 **재생성**할 수 있습니다. 생성에 실패한 컷도 재생성 버튼으로 다시 만듭니다.

### Stage 5 — 페이지 배치
- 선택한 컷들이 세로 스크롤 웹툰 레이아웃으로 자동 배치됩니다.

### Stage 6 — 말풍선 / 대사
- 한글 대사가 말풍선으로 자동 합성됩니다. 말풍선은 칸마다 나뉘어 인물 얼굴을 피해 놓이고, 나레이션은 컷 위 자막 띠로 들어갑니다.
- 감정에 따라 말풍선 모양이 달라집니다 (일반/분노/속삭임/생각/외침/슬픔).
- 말풍선 글꼴은 [원스토어 모바일POP체](https://www.onestorecorp.com/sv/fordev_font/)입니다. 재배포가 금지된 글꼴이라 프로그램에 포함하지 않고, 처음 말풍선을 합성할 때 공식 배포처에서 자동으로 내려받아 `fonts/` 폴더에 둡니다. 인터넷이 안 되면 맑은 고딕으로 표시됩니다.

### Stage 7 — 내보내기
- **PNG**: 전체 페이지 + 컷별 개별 이미지
- **PDF**: 인쇄·공유용 문서
- **ZIP**: 시나리오 JSON + 캐릭터 시트 + 컷 + 페이지 + PDF 전체 묶음

## 프로젝트 저장 & 불러오기

- 상단 헤더의 **저장** 버튼으로 현재 작업을 프로젝트로 저장할 수 있습니다.
- **불러오기** 버튼으로 이전에 저장한 프로젝트를 다시 열어 이어 작업합니다.

---

## 참고

- 모든 AI 호출은 설정 화면의 FactChat 게이트웨이 주소로만 전송됩니다.
- API 키는 내 PC의 `config` 폴더에만 저장되며, FactChat 외의 곳으로 전송되지 않습니다.
- 생성 결과물은 `outputs/` 폴더에 저장됩니다.
- 사용량(텍스트·이미지 호출 횟수)은 매달 1일 자동 초기화됩니다.
